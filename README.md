# proofwire.github.io

This repository exists for one reason: GitHub serves a hostname's root
(`https://proofwire.github.io/`) only from a repository named exactly
`proofwire.github.io`, and the site does not live here.

`index.html` redirects to <https://proofwire.github.io/proofwire/>, which is
built and deployed from [`site/` in proofwire/proofwire](https://github.com/proofwire/proofwire/tree/main/site).
Keeping the source in one place is why this is a redirect and not a copy.

Nothing else belongs here. To change the site, change it there.
